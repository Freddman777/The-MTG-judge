# The Judge's Bench

A searchable Magic: The Gathering rules reference in a single, self-contained HTML file. Type a term — `instant`, `trample`, `priority`, `commander damage` — and get a plain-language breakdown of **how it works, when it applies, and why it matters**.

No build step, no dependencies, no server. One file, open it and go.

## Features

- **Live search** across term names, aliases (`cmc` → Mana Value, `edh` → Commander), and the full text of every entry.
- **99 entries** spanning nine categories: Card Types, Zones, Turns & Phases, Core Rules, Combat, Keywords, Actions, Commander, and Formats.
- **How / When / Why** structure on every entry, so you get the mechanic, its timing window, and the reason it matters — not just a definition.
- **Clickable cross-references.** Terms mentioned inside an explanation link straight to their own entry, so a concept you don't know is one click away.
- **Category filters** to browse by area.
- **Rules-section pointers** to the official Comprehensive Rules for exact wording.
- **Dark, offline-capable, responsive** — works on desktop and mobile, keyboard-friendly.

## Usage

**Locally:** download `mtg-referee.html` and open it in any modern browser. That's it.

## Built with

Plain HTML, CSS, and vanilla JavaScript — no frameworks or libraries. Typography uses Google Fonts (Spectral, Inter, JetBrains Mono); the tool still works if those fail to load.

## Disclaimer

Every entry is written in plain language to explain how the rules function — it is **not** a copy of Wizards of the Coast's Comprehensive Rules. Rules-section numbers point to the official text for precise wording.

This is a study and quick-reference aid, **not** a substitute for the Comprehensive Rules or a certified judge for tournament rulings. For unusual card-specific interactions, check the card's Oracle text and Gatherer rulings.
